# Registro de Clientes

Aplicacion de escritorio desarrollada en C# utilizando Windows Forms. El proyecto consiste en un sistema de registro de clientes que permite ingresar datos en un formulario, validar la informacion de entrada y acumular los registros en una lista.

---

## Descripcion del proyecto

El programa consta de una interfaz grafica interactiva diseñada para el registro ordenado de usuarios, utilizando los siguientes elementos:

* Nombre (TextBox): Campo de texto para ingresar el nombre del cliente.
* Telefono (TextBox): Campo numerico para registrar un numero de telefono que debe contar con un minimo de nueve digitos.
* Correo (TextBox): Campo de texto para ingresar la direccion de correo electronico del cliente, la cual debe contener un caracter de arroba y un punto.
* Boton de registro (Button): Al hacer clic en este boton, el sistema verifica que todos los campos cumplan con el formato correcto antes de procesar el registro.
* Lista de clientes (ListBox): Recuadro donde se muestran de forma acumulada y numerada los datos de todos los clientes registrados exitosamente.

---

## Validaciones implementadas

El sistema aplica comprobaciones para garantizar que los datos ingresados sean correctos:

* Verificacion de campos vacios para evitar registros incompletos.
* Comprobacion de formato de correo electronico valido.
* Validacion de que el telefono tenga un minimo de nueve digitos y contenga exclusivamente numeros.
